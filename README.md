# .github

Organization-level GitHub configuration for **Aspenglow** (formerly Aspen Automation).

## What's here

| Path | Purpose |
|---|---|
| `profile/README.md` | Renders publicly on [github.com/Aspen-glow](https://github.com/Aspen-glow) |

`profile/README.md` is the org's public front page on GitHub. It is one of the `sameAs`
entity anchors described in finding **F-01** of the SEO audit, so its copy is kept
deliberately consistent with the other off-site profiles (LinkedIn, Crunchbase, Clutch).

## Editing it

Source of truth for this copy is `docs/tasks/profile-copy.md` in the `marketing-site`
repository. **Change it there first**, then mirror the change here.

The consistency is the point, not an accident: F-01's remediation depends on the same
description appearing identically across profiles, because that repetition is how search
engines and language models resolve which company is being referred to.

This repository is public — it must contain nothing client-related or confidential.
